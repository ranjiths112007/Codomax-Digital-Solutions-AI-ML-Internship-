# Day 1 — Introduction to AI, ML, and Deep Learning

## 1. What is Artificial Intelligence?

Artificial Intelligence (AI) is the broad area of computing focused on building systems that can perform tasks commonly associated with human intelligence. Examples include understanding language, recognising images, planning routes, and recommending content.

AI does not mean a machine is conscious or understands everything like a human. An AI system is designed for particular tasks and can make errors.

## 2. What is Machine Learning?

Machine Learning (ML) is a subset of AI. Instead of writing every rule manually, developers train a model using examples or data so it can learn patterns and produce predictions or decisions.

**Example:** A spam detector can learn from messages labelled as spam or not spam.

Common categories:
- **Supervised learning:** Learns from labelled examples, such as house details paired with their sale prices.
- **Unsupervised learning:** Looks for structure in data without supplied target labels, such as grouping customers by behaviour.
- **Reinforcement learning:** Learns actions through interaction and feedback, often described in terms of rewards.

## 3. What is Deep Learning?

Deep Learning (DL) is a subset of ML that uses neural networks with multiple layers. It is useful for complex patterns in images, audio, text, and other data. It often needs substantial data and computing resources, although requirements depend on the task.

## 4. How are AI, ML, and DL related?

- AI is the broadest category.
- ML is one approach within AI.
- DL is one approach within ML.

A model can be AI without being ML—for example, a system that follows manually written rules. An ML model can also use techniques other than deep neural networks.

## 5. Everyday applications

| Area | Example | What the system does |
|---|---|---|
| Healthcare | Medical-image support | Helps flag patterns for professional review |
| Finance | Fraud detection | Scores transactions for unusual patterns |
| Retail | Recommendations | Suggests items based on observed preferences |
| Transport | Route estimation | Estimates travel time and suggests routes |
| Agriculture | Plant-image analysis | Helps identify possible crop diseases |
| Language | Speech recognition | Converts spoken audio into text |
| Customer service | Chatbots | Responds to questions using rules or learned models |

## 6. Important terms

- **Data:** Examples or observations used by a system.
- **Feature:** An input property used by a model.
- **Label/target:** The answer a supervised model is trained to predict.
- **Model:** A learned mathematical representation that maps inputs to outputs.
- **Training:** The process of learning model parameters from data.
- **Inference:** Using a trained model to generate an output.
- **Prediction:** A model's estimated answer; it is not guaranteed to be correct.
