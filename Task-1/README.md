# Task 1 — Introduction to AI & Python

**Level:** Beginner  
**Duration:** Day 1–Day 4

## Objectives
- Understand the basics of Artificial Intelligence (AI) and Machine Learning (ML).
- Explain the difference between AI, ML, and Deep Learning.
- Identify real-world applications of AI.
- Practise Python variables, data types, operators, loops, conditions, lists, and functions.
- Write and test beginner-level Python programs.

## Files
- `ai_ml_dl_and_real_world_applications.md` — AI, ML, Deep Learning, use cases, and review questions.
- `python_basics.py` — Python fundamentals and examples.
- `control_flow_and_lists.py` — Conditions, loops, and list practice.
- `beginner_programs.py` — Beginner programming exercises.
- `test_beginner_programs.py` — Unit tests for the beginner programs.

## Run the examples
From the repository root, run a Python file with:

```bash
python Task-1/python_basics.py
python Task-1/control_flow_and_lists.py
python Task-1/beginner_programs.py
```

Run the tests (Python 3.11+ recommended):

```bash
python -m unittest Task-1/test_beginner_programs.py
```

This folder groups all four days of work under **Task 1**, rather than separating the repository by day.
