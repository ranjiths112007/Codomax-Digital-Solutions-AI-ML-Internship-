# Task 3 — Data Analysis & Visualization

**Module 03 | Day 9–Day 12 | Intermediate**

## Project
Sales Data Analysis & Visualization using Pandas, NumPy, and Matplotlib.

## Objectives covered
- Load and explore a dataset.
- Inspect data types, summary statistics, and missing values.
- Clean missing values and duplicate rows.
- Analyze revenue by product, region, and month.
- Create bar, line, and pie charts.

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Choose **File → Upload notebook**.
3. Upload `Module_03_Data_Analysis_Visualization.ipynb`.
4. Choose **Runtime → Run all**.
5. Save/download the notebook with outputs and submit it as required.

The sample dataset is generated inside the notebook; no separate data file is needed.
