# Task 4 — Machine Learning Fundamentals

**Module 04 | Day 13–Day 16 | High**

## Project
Iris Flower Classification using Scikit-learn.

## Objectives covered
- Understand a basic supervised machine learning workflow.
- Load and explore the Iris dataset.
- Split data into training and testing sets.
- Train a Random Forest classifier.
- Evaluate the model using accuracy, a classification report, and a confusion matrix.
- Predict a new flower's species and interpret the result.

## Run in Google Colab
1. Open https://colab.research.google.com/
2. Choose **File → Upload notebook**.
3. Upload `Module_04_Machine_Learning_Fundamentals.ipynb`.
4. Choose **Runtime → Run all**.
5. Save/download the notebook with outputs and submit it as required.

The dataset is included with Scikit-learn; no separate download is needed.
